# GiftCode 🎁

منصة هدايا رقمية تفاعلية مستقلة، تدعم iOS وAndroid والكمبيوتر.

## النسخة الحالية
نموذج أولي ثابت، مع متجر بثلاثة قوالب وأسعار تبدأ من 1 دينار أردني، ومحرر ومعاينة وروابط تجريبية. لا توجد مدفوعات حقيقية أو قاعدة بيانات أو صلاحيات إدارة آمنة بعد.

## التشغيل
افتح `index.html` أو انشره عبر GitHub Pages. لا تستخدم بيانات شخصية حساسة أو إثباتات دفع في النموذج.

## خارطة الطريق
- ربط قاعدة بيانات وتسجيل دخول وصلاحيات
- قوالب متحركة ومحرر للهدايا
- طلبات خاصة ومراجعة دفع يدوي آمنة
- روابط هدايا خاصة وQR
- اختبار على iPhone وAndroid
